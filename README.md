# ByteBank — Sistema Bancário em Java

Projeto desenvolvido em Java com o objetivo de praticar Programação Orientada a Objetos e padrões de projeto (Design Patterns).

## Sobre o projeto

O ByteBank é um sistema bancário que permite trabalhar com conceitos de gerenciamento de contas e operações bancárias, aplicando boas práticas de organização e estruturação de código.

## Tecnologias utilizadas

- Java
- Programação Orientada a Objetos
- Git
- GitHub

## Design Patterns aplicados

- **Singleton:** controle de instância única.
- **Strategy:** organização de diferentes estratégias.
- **Builder:** construção de objetos.
- **Factory:** criação de objetos.
- **Observer:** comunicação entre objetos por notificações.

## Objetivos de aprendizagem

- Praticar Java e orientação a objetos.
- Aplicar padrões de projeto.
- Melhorar a organização e legibilidade do código.
- Desenvolver habilidades de programação.
